Security reminder

Keep this workspace private and make sure the database—not only the screen—enforces who can read or change records.

Important: never put a Supabase service_role or secret key in HTML or browser JavaScript. Use a publishable/anon key in the browser and set Row Level Security policies so only trusted administrators can access sensitive order and customer data.
